## TC-19-001: Таблица клиентов отображается для всех разрешённых ролей

**Priority:** High
**Type:** Functional
**Related AC:** US-19-1 (#35)

### Preconditions
- Пользователь авторизован с ролью admin (или manager, или mechanic)
- Firestore коллекция `clients` содержит 3 документа с полями fullName, phone, email, createdAt

### Steps
| Step | Action | Expected Result |
|------|--------|----------------|
| 1 | Перейти на /dashboard/clients | Страница загружается без ошибок |
| 2 | Проверить наличие data-testid="clients-table" | Элемент таблицы присутствует в DOM |
| 3 | Проверить заголовки колонок | Видны колонки «ФИО», «Телефон», «Email», «Добавлен», «Действия» |
| 4 | Подсчитать строки таблицы | В таблице 3 строки клиентов (data-testid="client-row-{id}") |
| 5 | Проверить порядок строк | Клиент с наибольшим createdAt отображается первым (сортировка по убыванию) |

### Expected Result
Таблица клиентов отображается корректно со всеми пятью колонками и строками, отсортированными по дате создания (убывание).

### Test Data
- client-1: { fullName: "Іваненко Іван Іванович", phone: "+380501112233", email: "ivan@example.com", createdAt: 2026-05-01 }
- client-2: { fullName: "Петренко Петро Петрович", phone: "+380672223344", email: "petro@example.com", createdAt: 2026-05-10 }
- client-3: { fullName: "Коваль Олена Сергіївна", phone: "+380933334455", email: "", createdAt: 2026-05-15 }

## TC-19-010: Поиск по имени фильтрует таблицу в реальном времени

**Priority:** High
**Type:** Functional
**Related AC:** US-19-4 (#38)

### Preconditions
- Пользователь авторизован с ролью manager
- Страница /dashboard/clients загружена с 4 клиентами в таблице

### Steps
| Step | Action | Expected Result |
|------|--------|----------------|
| 1 | Найти поле поиска (data-testid="clients-search-input") | Поле присутствует и пустое |
| 2 | Ввести "іван" (2+ символа, нижний регистр) | Символы вводятся |
| 3 | Подождать не более 300 мс (debounce) | Таблица обновляется |
| 4 | Подсчитать строки таблицы | Отображаются только клиенты, у которых fullName содержит «іван» (без учёта регистра) |
| 5 | Убедиться, что остальные клиенты скрыты | Строки Петренко, Коваль, Сидоренко не отображаются |
| 6 | Убедиться, что сетевой запрос не выполнялся | В Network нет новых вызовов к Firestore |

### Expected Result
Таблица фильтруется клиентски (client-side) без обращения к Firestore. Поиск нечувствителен к регистру. Видны только совпадающие строки.

### Test Data
- clients: [{ fullName: "Іваненко Іван Іванович", phone: "+380501112233" }, { fullName: "Іванова Тетяна", phone: "+380671234567" }, { fullName: "Петренко Петро", phone: "+380672223344" }, { fullName: "Коваль Олена", phone: "+380933334455" }]
- search query: "іван"
- expected matches: "Іваненко Іван Іванович", "Іванова Тетяна"

## TC-19-012: Очищение поля поиска показывает всех клиентов

**Priority:** Medium
**Type:** Functional / Edge Case
**Related AC:** US-19-4 (#38)

### Preconditions
- Пользователь авторизован с ролью manager
- Страница /dashboard/clients загружена с 4 клиентами
- В поле поиска введён запрос "іван", таблица показывает 2 совпадения

### Steps
| Step | Action | Expected Result |
|------|--------|----------------|
| 1 | Убедиться, что в таблице 2 строки (результат поиска "іван") | Таблица отфильтрована |
| 2 | Очистить поле поиска (удалить все символы) | Поле пустое |
| 3 | Подождать не более 300 мс | Таблица обновляется |
| 4 | Подсчитать строки таблицы | Отображаются все 4 клиента |
| 5 | Убедиться, что нет сетевых запросов | В Network нет новых вызовов к Firestore |

### Expected Result
При пустой строке поиска (или менее 2 символов) фильтр сбрасывается и в таблице отображаются все клиенты. Сетевого запроса не происходит.

### Test Data
- clients: [{ fullName: "Іваненко Іван" }, { fullName: "Іванова Тетяна" }, { fullName: "Петренко Петро" }, { fullName: "Коваль Олена" }]
- initial search query: "іван" → 2 results
- cleared query: "" → 4 results
