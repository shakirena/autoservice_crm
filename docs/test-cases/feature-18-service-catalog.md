## TC-18-001: Страница /dashboard/services доступна менеджеру

**Priority:** High
**Type:** Functional
**Related AC:** US-18-1 (#28)

### Preconditions
- Пользователь авторизован с ролью manager
- Firestore содержит 2 категории и 3 услуги

### Steps
| Step | Action | Expected Result |
|------|--------|----------------|
| 1 | Перейти на /dashboard/services | Страница загружается без ошибок |
| 2 | Наблюдать за содержимым | Видны секция «Категории услуг» и секция «Услуги» |
| 3 | Проверить data-testid="services-page" | Элемент присутствует в DOM |
| 4 | Проверить наличие списков | В секции «Категории» отображаются 2 категории, в секции «Услуги» — 3 услуги |

### Expected Result
Страница отображает две панели. Кнопки «Добавить категорию» и «Добавить услугу» отсутствуют (нет прав на запись).

### Test Data
- category: { name: "ТО", vehicleComponent: "engine" }
- category: { name: "Кузов", vehicleComponent: "body" }
- service: { name: "Замена масла", price: 500, archived: false, category: "ТО" }

## TC-18-002: Пустое состояние — нет категорий и услуг

**Priority:** Medium
**Type:** Functional
**Related AC:** US-18-1 (#28)

### Preconditions
- Пользователь авторизован с ролью manager или admin
- Firestore не содержит ни одной категории и ни одной услуги

**Related AC:** US-18-1 (#28)

### Preconditions
- Пользователь авторизован с ролью mechanic
- RoleGuard настроен для маршрута /dashboard/services (допустимые роли: admin, manager)

### Steps

| 1 | Перейти напрямую на /dashboard/services | Происходит редирект |

## TC-18-016: Удаление категории блокируется при наличии активных услуг

**Priority:** High
**Type:** Business Rule / Functional
**Related AC:** FR-5

### Preconditions
- Пользователь авторизован с ролью admin
- Firestore содержит категорию "ТО" с 2 активными (archived=false) услугами

### Steps
| Step | Action | Expected Result |
|------|--------|----------------|
| 1 | Найти категорию "ТО" в списке категорий | Категория видна |
| 2 | Нажать кнопку «Удалить» у категории "ТО" (data-testid="delete-category-btn") | Появляется диалог подтверждения или немедленно выдаётся ошибка |
| 3 | Подтвердить удаление (если есть диалог) | Система пытается выполнить удаление |
| 4 | Проверить результат | Появляется сообщение об ошибке (data-testid="delete-category-error") |
| 5 | Проверить категорию в списке | Категория "ТО" по-прежнему присутствует в Firestore и списке |
| 6 | Убедиться, что услуги не удалены | 2 услуги категории "ТО" остаются активными |

### Expected Result
Удаление категории заблокировано (FR-5). Отображается понятное сообщение об ошибке, поясняющее, что категорию нельзя удалить, пока в ней есть активные услуги. Данные в Firestore не изменились.

### Test Data
- category: { name: "ТО", vehicleComponent: "engine" }
- services: [{ name: "Замена масла", category: "ТО", archived: false }, { name: "Проверка фильтров", category: "ТО", archived: false }]
