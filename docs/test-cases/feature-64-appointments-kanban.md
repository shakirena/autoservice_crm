# Test Cases — Feature #64: Kanban доска записи клиентов

_Дата: 2026-05-25_

## TC-64-01: Создание анонимной записи
**Story:** #66
**Steps:**
1. Открыть страницу /dashboard/appointments
2. Нажать "Новая запись"
3. Выбрать режим "Анонимная запись"
4. Заполнить телефон и имя клиента
5. Выбрать дату, время, тип услуги
6. Нажать "Сохранить"
**Expected:** Запись создана с clientId=null, отображается в канбан-колонке "Ожидает"

## TC-64-02: Привязка клиента к анонимной записи
**Story:** #68
**Steps:**
1. В канбан-доске найти анонимную запись
2. Нажать "Привязать клиента"
3. Выбрать клиента из справочника
4. Нажать "Привязать"
**Expected:** clientId заполнен, кнопка "Привязать клиента" исчезает

## TC-64-03: Создание записи с новым клиентом
